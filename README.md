# PaperManager
A manage tool for academic paper，support pdf/markdown files

## 启动

```bash
pip install -r requirements.txt
python main.py
```

## 功能一览

### 文献库
- 左侧 **内容库**:`库 → 分类 → 子分类 → …` 无限层级,右键或双击(F2)可新建/重命名/删除
- 虚拟视图:**全部文献 / 星标文献 / 最近阅读**(7 天内)
- **摘录库**:阅读时摘录的内容以卡片形式集中展示

### 文献导入(三种方式)
1. **拖拽** PDF/MD/TXT/HTML/EPUB 文件到窗口 → 自动复制到 `resources/papers/` 并刷新
2. **手动**把文件放进 `resources/papers/` → 启动时或点 ⟳ 刷新时自动扫描
3. **下载工具**(左下角):粘贴文献直链网址(校园网数据库可直接访问的 PDF 链接),通过 curl 下载入库,输出显示在控制台

### 卡片
- 圆角卡片 = 上部「文献名彩色封面」+ 下部操作区
- 悬停显示文献全名;封面含类型角标、阅读进度条
- **状态**按钮:阅读状态(未读/阅读中/已读 + 进度%)、添加日期、星标、上次阅读时间、阅读时长、标签,可直接编辑
- **删除**按钮:`从项目中移除`(保留文件,不再扫入)/ `从磁盘删除`(移入 `resources/_trash/` 可找回)
- 右上筛选栏:搜索、标签、阅读状态、仅星标、排序(时间/最近阅读/时长/标题)

### 预览(单击卡片)
其他区域变暗,原卡片保持显示,旁边生成大卡片展示文献第一页;点暗处或 ESC 关闭,点原卡片直接进入阅读。

### 阅读(双击卡片)
- 浏览器式**多标签页**,可拖动排序、逐个关闭
- 右侧**竖排工具栏**:
  - 🖍 **高亮标注模式**:框选文字即高亮(持久保存)
  - 📌 **标记本页**:给当前页加书签丝带
  - ✂ **摘录模式**:框选文字弹出摘录输入卡 → 绿✓存入摘录库 / 红✗取消(Markdown 文档为选中文字即触发)
  - 👁 **显示/隐藏标注与标记**
  - ＋/－/▢ 缩放;底部显示页码/进度
- 自动记录阅读进度、阅读时长、上次阅读时间(窗口前台时每 5 秒累计)

### 其它
- 深/浅色主题一键切换(右上角 ☀/☾)
- 侧边栏可折叠(左上角 ◂/▸)

## 支持格式

`pdf` `md/markdown` `txt` `html/htm` `epub`(EPUB 按 PDF 方式分页渲染)
